# 🌸 CapyMeal

> Las comidas pasan. Los recuerdos quedan.

## ¿Qué es CapyMeal?

CapyMeal es un diario digital pensado para guardar los pequeños momentos alrededor de la comida.

No es una aplicación para contar calorías.
No es una herramienta para juzgar hábitos.

Es un espacio para recordar.

## Nuestra misión

Crear un lugar tranquilo donde las personas puedan registrar sus días de una forma simple, cálida y agradable.

## Capi 🐹

Capi es un pequeño carpincho que acompaña al usuario.

No controla.
No exige.
No corrige.

Acompaña.

## Principios

- La simplicidad siempre gana.
- Registrar debe sentirse agradable.
- Las comidas forman parte de historias.
- La aplicación nunca debe generar culpa.
- Cada detalle debe aportar calma.

## Nuestra frase

"Las comidas pasan. Los recuerdos quedan."
