# 🗺️ CapyMeal Roadmap

> Plan de desarrollo del proyecto CapyMeal.

---

# Visión

CapyMeal nace como un diario digital para registrar las comidas y los pequeños momentos que las acompañan.

Nuestro objetivo no es crear una aplicación para controlar hábitos.

Nuestro objetivo es crear un lugar agradable donde guardar recuerdos cotidianos.

Cada versión debe acercarnos a esa visión.

# 🌸 Versión 0.1 — Prototipo Visual

Estado:

🟡 En progreso

Objetivo:

Construir una versión navegable sin persistencia de datos.

Incluye:

- Home
- Registro diario
- Diario
- Exportar PDF (simulado)
- Ajustes
- Responsive
- Componentes reutilizables

No incluye:

- Backend
- Base de datos
- Login

Meta:

Validar la experiencia de uso.

# Prioridades

## Prioridad máxima

Registrar un día.

Todo lo demás es secundario.

---

## Prioridad alta

Experiencia de usuario.

CapyMeal debe sentirse agradable incluso con pocas funcionalidades.

---

## Prioridad media

Exportación PDF.

---

## Prioridad baja

Funciones sociales.

---

# Criterio de éxito

Una versión se considera terminada cuando:

- cumple su objetivo
- fue probada
- está documentada
- mantiene la filosofía de CapyMeal

No se agregan nuevas funciones antes de cerrar la versión actual.

---

# Nuestra regla

No desarrollamos por impulso.

Desarrollamos paso a paso.

Cada versión debe dejar el proyecto mejor de lo que estaba ayer.

---

# Frase del proyecto
