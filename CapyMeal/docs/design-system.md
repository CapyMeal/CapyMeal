# 🎨 CapyMeal Design System

> La identidad visual de un diario cálido para guardar momentos.

---

# 1. Identidad visual

CapyMeal busca transmitir:

- 🌸 calma
- 🐹 compañía
- ☕ calidez
- 📖 recuerdos
- 🌿 tranquilidad

La aplicación debe sentirse como abrir una libreta bonita en un lugar cómodo.

No busca llamar la atención con exceso de elementos.
Busca acompañar.

---

# 2. Personalidad de marca

## Capi 🐹

Capi representa:

- compañía
- curiosidad
- ternura
- tranquilidad

Capi nunca juzga.
Nunca presiona.
Nunca exige.

Capi acompaña.

---

# 4. Tipografías

## Títulos

Preferencia:

- Fredoka
- Quicksand
- Nunito

Características:

- redondeada
- amigable
- cercana

---

## Texto

Preferencia:

- Inter

Características:

- limpia
- fácil de leer
- moderna

---

# 5. Componentes

## Botones

Los botones deben:

- tener bordes redondeados
- ser grandes y cómodos
- transmitir calma
- evitar colores agresivos

Ejemplo:

🩷 Guardar mi día

---

## Tarjetas

Las tarjetas representan momentos.

Características:

- fondo claro
- bordes suaves
- esquinas redondeadas
- sombras ligeras

---

# 6. Espaciado

CapyMeal debe sentirse tranquila.

Preferimos:

- espacios amplios
- pocos elementos juntos
- respiración visual

---

# 7. Ilustraciones

Las ilustraciones deben sentirse:

- suaves
- cálidas
- simples
- amigables

Capi debe aparecer como acompañante, no como decoración.

---

# 8. Regla principal

Antes de agregar cualquier elemento visual preguntamos:

> "¿Esto hace que CapyMeal se sienta más cálida y fácil de usar?"

Si la respuesta es no, no pertenece.
